```markdown
## MCP Diet

Prefer task profiles over a full MCP stack. Invoke skill **MCP Diet** (or `/MCP Diet`) when starting a session or switching task type.

| Profile | Intent |
|---------|--------|
| code | forge / PR / browser / docs-API / ui-kit |
| docs | Notion-like + light forge |
| design | Figma-like + design-ref + ui-kit |
| sheets / slides / research / chat | as named |
| full | rare cross-service only |

Default for engineering: `code`. Keep Notion-class MCP **off** outside docs/sheets/slides. Skills without MCP schemas (lint/review helpers) are fine always-on.
```
